# 하루한칸

깔끔한 메모장 형태의 할 일 앱입니다. 중요도 높은 순으로 정리하고, 끝낸 일은 체크할 수 있습니다. 날짜별 목록, 수정·삭제, 완료 필터와 진행률을 제공합니다.

## 실행

Node.js 24를 사용하세요. 현재 환경에서는 Node.js 24와 npm 11로 확인했습니다. 저장소 최상위의 기존 스튜디오인 사이트와는 별도 앱입니다.

```sh
cd apps/checklist
npm ci
npm run dev
```

위 명령은 저장소 최상위에서 시작합니다. 프로덕션 실행은 이 앱 폴더에서 `npm run build` 후 `npm run start`입니다. 개발 서버와 프로덕션 빌드는 같은 `.next` 폴더를 쓰므로 동시에 실행하지 마세요.

## 별도 주소로 배포

Vercel에서 새 프로젝트를 만들고 `jangi-an/studioian` 저장소를 선택한 뒤 Root Directory를 `apps/checklist`로 지정하세요. Framework Preset은 Next.js입니다. 이 프로젝트에도 아래의 Supabase 환경 변수 두 개를 등록해야 합니다. 기존 스튜디오인 프로젝트의 설정은 변경하지 않습니다.

## 휴대폰과 컴퓨터에서 같은 목록 보기

1. `.env.example`의 두 환경 변수를 실제 Supabase 프로젝트 값으로 설정합니다. 공개 키 또는 구형 anon 키를 사용하며 service-role 키는 사용하지 않습니다. 기존 클라우드 환경에는 두 변수가 이미 등록되어 있습니다.
2. Supabase SQL Editor에서 [supabase/setup.sql](supabase/setup.sql)을 한 번 실행합니다. 이 스크립트는 할 일 테이블과 계정별 접근 정책을 만듭니다. 재실행해도 기존 할 일을 지우지 않습니다.
3. Supabase Authentication에서 이메일 가입을 활성화하고, URL Configuration의 Site URL을 실제 앱 주소로 설정합니다. Redirect URLs에는 `실제앱주소/auth/callback`을 허용합니다.
4. 회원가입 확인 메일은 가입한 브라우저에서 엽니다. 두 기기에서 같은 계정으로 로그인합니다.

앱의 `/setup` 화면에도 복사 버튼과 순서 안내가 있습니다. 설정을 완료하기 전에도 로그인하지 않고 이 기기에서 먼저 쓸 수 있습니다. 이 경우 목록은 해당 브라우저에만 저장되며, 기기 간 공유되지 않습니다. 로그인 후 기기에 적어둔 목록을 계정으로 옮길 수 있습니다.

로그인한 목록은 Supabase에 저장됩니다. 10초마다, 창이 다시 활성화될 때, 인터넷에 재접속할 때 목록을 갱신합니다. 새로고침 버튼으로 즉시 갱신할 수도 있습니다. 오프라인에서 온라인 저장에 실패하면 성공으로 표시하지 않으며 입력한 내용은 지우지 않습니다.

## 검증

```sh
node --test tests/todos.test.mjs
npm run build
```

개발 환경에 별도 린트 설정은 없습니다. 로컬 브라우저 검증에서 추가·수정·삭제, 완료 체크, 중요도 정렬, 새로고침 후 보존, 날짜 이동, 휴대폰 레이아웃을 확인합니다. 실제 기기 간 동기화는 위 Supabase 설정과 실제 계정으로 추가 확인해야 합니다.
